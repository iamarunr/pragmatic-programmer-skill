# Pragmatic Programmer AI Skill

This repository contains a custom AI skill designed to bring the principles of *The Pragmatic Programmer* (by Andy Hunt and Dave Thomas) to AI coding assistants.

## How to use
You can use the `SKILL.md` file as a system prompt, custom instruction, or a specific `@` mentioned skill for AI coding agents like Antigravity, GitHub Copilot, or ChatGPT.

Drop the `SKILL.md` file into your `.gemini/skills/` directory (or equivalent agent skill folder) to automatically apply these pragmatic principles to your generated code and code reviews!
